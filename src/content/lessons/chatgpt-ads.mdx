## The ad experience

OpenAI describes ChatGPT advertising around moments when people explore options, compare alternatives and make decisions in a conversation. That makes the surrounding task and context part of the starting point for understanding an ad’s relevance. [ChatGPT advertiser overview](https://ads.openai.com/)

For an advertiser, the next questions are practical. Which settings can you change? Which actions can you measure? Which results can your software pull into a report?

An ad account contains campaigns, campaigns contain ad groups, and ad groups contain ads. An API is how software sends a request to another system. The Advertiser API lets software manage campaigns and request reports. When you build a report, keep each campaign’s ID and settings alongside its results. [Advertiser API and campaign structure](https://developers.openai.com/ads/api-overview)

A measurement pixel is a small piece of website code that records actions. The Conversions API lets your server send records of actions such as purchases. Sending those records and requesting a campaign report are separate jobs. [Measurement interfaces](https://developers.openai.com/ads)

An Ads API key is a secret your server uses to access a specific ad account. Using ChatGPT and getting advertiser API access are separate. Before connecting a live account, check that you have access and that the features you need are available. [Advertiser API authentication](https://developers.openai.com/ads/api-reference/authentication)

## What the reports tell you

A report can show impressions, clicks and spend, for example by campaign and day. The reasons an ad was considered, scored or chosen for a particular conversation stay inside the platform.

## Optimisation and evidence

Ask what the campaign aims to achieve, what you pay for and what the report measures. With conversion-optimised cost per click (CPC), the campaign aims for a chosen action, such as a purchase, and you pay for valid clicks. It requires an eligible ad account and conversion tracking. An order credited to an ad tells you how the platform counted it. To estimate how many extra sales the ad caused, you need a comparison. [Conversion-optimised campaign requirements](https://developers.openai.com/ads/conversion-optimized-campaigns)

Before changing a budget or ad, check what the report measures and whether more data may arrive. The measurement guides will look at how to use these results and how to estimate the extra sales a campaign caused, known as incrementality.
