# Harness first slice · 7 November 2026

## Scope and brief

Owner-requested first implementation slice: inherit the shared brand, build the new homepage, restructure navigation around five engineering tracks, and preserve the existing visualizers. The deliverable is the local Vite/React application. No new API integrations, completed courses, videos, production project walkthroughs, or deployment are represented as available.

Audience: builders working across marketing, growth, and go to market. Message: understand principles, inspect code, and build systems that bring AI products to market.

Visual thesis: the publication's static optical sphere gives the entrance a recognisable visual field; strong Arial headings and solid reading surfaces keep practical learning clear.

Content plan: entrance and actions → practical orientation → five tracks → available visualizers and control-plane pattern → curated reading → publication/Skills/Harness relationships. Each track separates available resources from the curriculum outline.

Interaction thesis: ordinary links, active-track indication, native mobile navigation, visible keyboard focus, saved reading theme, and user-controlled visualizer playback. Ambient artwork and titles remain static. Reduced-motion mode removes smooth scrolling and transitions.
